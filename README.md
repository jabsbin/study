# 너를 위한 작은 생일 동산

Three.js 기본 도형으로 만든 파스텔 생일 정원입니다. 유료 API, 인증 키, 외부 3D 모델 없이 실행됩니다. 오르골과 효과음은 Web Audio API로 직접 합성합니다.

## 실행

Node.js 22.12+ 환경에서 (24 권장):

```sh
npm ci
npm run dev
```

기본 개발 서버(5173)는 혼자서 화면과 이벤트를 개발하는 모드입니다. 친구와 함께하는 동작은 아래 명령으로 Cloudflare Workers와 Durable Object를 로컬 실행한 뒤 8787 포트에서 확인하세요.

```sh
npm run dev:shared
```

배포 시 Cloudflare에서 GitHub `main`을 연결하고 빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy`를 사용하세요. `wrangler.jsonc`가 정적 파일과 실시간 서버를 함께 배포하고 SQLite Durable Object를 생성합니다. 별도 API 키는 앱에 필요하지 않습니다. `dist/`만 정적 호스팅에 올리면 실시간 연결 없이 혼자 산책하는 모드로 작동합니다.

## 산책하기

- WASD / 방향키: 이동, Shift: 달리기
- 마우스·터치 드래그: 카메라 회전, 마우스 휠 / 모바일 두 손가락 벌리기: 줌
- E 또는 화면의 상호작용 버튼: 가까운 선물·케이크·편지와 상호작용
- 오두막 의자·별빛 정원 벤치: 가까이에서 E 또는 화면 버튼으로 앉기, 다시 E 또는 버튼으로 일어나기
- 편지 양옆 벤치에는 각각 좌우 두 자리와 방석이 있습니다. 가까운 빈자리를 선택합니다.
- 모바일: 왼쪽 조이스틱으로 이동
- 오른쪽 위 ♫: 소리 켜기·끄기, ?: 조작 도움말
- 왼쪽 위 나의 미션: 눌러서 접기·펼치기 (모바일에서는 처음에 접혀 있습니다)

왼쪽 곰돌이 정원에서 선물 3개를 열고, 중앙 케이크에서 소원을 빌어보세요. 케이크 뒤 정자의 빛나는 봉투에는 마지막 편지가 있습니다. 케이크 이벤트는 반복할 수 있고, 열린 선물은 현재 방문 동안 열린 상태로 유지됩니다. 새로고침하면 다시 시작합니다.

## 친구와 함께 앉기

배포된 같은 주소에 접속해서 입장하면 같은 동산에 연결됩니다(최대 8명). 다른 접속자는 파란 후드티와 “친구 ♡” 이름표로 표시됩니다. 위쪽의 “동산에 N명” 표시로 연결 여부를 확인하세요.

벤치의 분홍·보라 방석은 각각 독립된 자리입니다. 두 사람이 같은 자리를 동시에 선택해도 서버에서 한 사람만 허용합니다. 친구가 일어나거나 연결을 종료하면 자리가 비워집니다. 연결이 끊기면 안전하게 일어나고 재연결을 시도합니다. 연결할 수 없는 환경에서는 “혼자 산책 중”으로 표시됩니다.

캐릭터의 위치·방향·앉은 자리와 감정 표현을 공유합니다. 이동은 최대 초당 20회로 전달하며, 다른 캐릭터는 송신 시각과 최근 위치 기록 사이를 보간해서 표시합니다. 약 120ms의 기록으로 통신 간격의 흔들림을 흡수하고, 짧은 누락만 최대 80ms까지 예측한 뒤 멈춥니다. 이동 정보만 전송하고, 접속·좌석 변경 때 전체 상태를 맞춥니다. 케이크 앞에서 한 사람이 E를 누르면 같은 동산의 모든 접속자가 서버 기준 시각으로 소원·촛불·폭죽·멜로디를 함께 체험합니다. 도중에 입장한 사람도 진행 중인 장면부터 이어 봅니다. 이벤트 중 이동은 모두 잠시 멈추며, 끝난 뒤 다시 실행할 수 있습니다. 선물과 편지는 각자 체험합니다.

서버는 접속 정보와 최근 축하 이벤트의 시각만 보관하며 로그인과 채팅은 없습니다.

## 이름을 넣은 선물 링크

`https://사이트주소/?name=지민`으로 접속하면 입장 인사·사이트 제목·케이크 간판·편지 제목에 지민의 이름이 나옵니다. 이름은 Unicode 정규화 후 최대 20자로 처리하며 HTML로 해석하지 않습니다. 이름이 없으면 원래 문구가 표시됩니다.

“함께 · 도구 → 선물 링크”에서 이름을 입력하고 주소를 복사할 수도 있습니다. 코드 수정이나 재배포는 필요하지 않습니다. 같은 이름으로 입장한 사람끼리 같은 동산에 연결되고, 다른 이름의 동산은 구분됩니다.

## 닉네임과 방명록

입장 화면에서 닉네임을 선택할 수 있습니다(최대 12자). 닉네임은 캐릭터 위, 채팅, 방명록 작성자에 표시되고 같은 기기에서 다음 입장 때 기억합니다. 비워 두면 자동으로 친구 번호가 붙습니다. 닉네임은 링크의 생일 주인공 이름이나 동산 구분에 영향을 주지 않습니다.

“함께 · 도구 → 방명록”에서 축하 메시지를 남기세요. 같은 이름의 동산끼리 공유하며 Cloudflare Durable Object 저장소에 보관하므로 새로고침하거나 모두 나가도 남습니다. 메시지는 최대 200자, 10초 간격으로 작성할 수 있고 최신 20개부터 “이전 메시지 더 보기”로 읽습니다. 전송 실패 시 작성한 내용을 유지하며 다시 눌러도 중복 저장하지 않습니다. 방명록도 `npm run dev:shared` 또는 배포한 사이트에서 사용할 수 있습니다.

## 채팅

보낸 채팅은 캐릭터 머리 위 말풍선에도 8초 동안 나타납니다. 긴 말풍선은 4줄까지 보이며 전체 내용은 채팅 목록에서 확인합니다.

오른쪽 아래 **채팅** 버튼으로 같은 동산의 친구들과 이야기할 수 있습니다. PC에서는 Enter로 입력창을 열고 Esc로 접습니다. 입력 중에는 캐릭터가 움직이지 않습니다. 친구 번호는 접속 중 자동 배정되며, 메시지는 최대 200자이고 빠른 연속 전송은 제한합니다. 대화는 저장하지 않으며 입장 이후의 메시지만 표시합니다. 새로고침하면 대화 목록이 비워집니다. 기본 개발 서버에서는 채팅이 비활성화되므로 `npm run dev:shared`로 확인하세요.

## 감정 표현과 기념사진

“함께 · 도구”에서 인사(손 흔들기)·하트·박수를 선택하면 친구에게도 보입니다. 서 있거나 벤치에 앉아 있을 때 모두 사용할 수 있습니다.

박수는 현재 카메라를 향해 캐릭터가 돌아서 치고, 끝나면 원래 방향으로 돌아옵니다. 카메라 구도는 유지합니다.

“기념사진”은 화면 UI를 숨기는 사진 모드입니다. 드래그로 구도를 맞추고 “사진 찍기 → PNG 저장”을 누르세요. 긴 변 1920px의 PNG가 생성됩니다. 모바일은 미리보기 사진을 길게 눌러 저장하거나, 지원되는 브라우저에서 공유하기를 사용할 수 있습니다. “돌아가기” 또는 Escape로 사진 모드를 종료합니다.

“시점 초기화”는 캐릭터 뒤쪽의 기본 시점으로 돌아갑니다. 모바일 세로 화면에서 같은 벤치에 앉은 두 사람이 함께 들어오도록 중간 지점을 바라보고 거리를 맞춥니다.

## 문구 수정

`src/content.js`의 `BIRTHDAY_LETTER`와 `GIFT_MESSAGES`를 수정하세요. 소리와 멜로디는 `src/audio.js`, 월드와 이벤트는 `src/main.js`, 화면 디자인은 `src/style.css`에 있습니다.

## 검증

```sh
npm run build
npx playwright install chromium # 시스템 Chromium이 없는 경우 한 번 설치
npm test
```

추가 실시간 검증:

```sh
npm run test:shared # 채팅, 이름별 연결, 공동 축하, 감정 표현, 2인 착석과 세로 화면 기념사진
# 동기화 서버가 켜져 있는 상태(npm run dev:shared)에서 다른 터미널로 실행:
npm run test:motion # 이동 지연·패킷 흔들림·각도 경계·정지·착석 보간 검증
npm run test:room   # Durable Object 좌석 경쟁·동산 분리·이벤트 중복 방지·늦은 접속 복구
```

브라우저 테스트는 실제 키보드 이동으로 선물 3개, 촛불 이벤트 반복, 이벤트 중 이동 정지, 편지 열기·닫기, 모바일 조이스틱, 의자 2개와 벤치 좌우 4곳에서 앉기·일어나기와 모바일 터치 버튼, 선물 링크 복사, PNG 다운로드, 핀치 줌·시점 초기화와 이름의 HTML 주입 방지도 확인합니다. 시스템에 `/usr/bin/chromium`이 있으면 해당 브라우저를 사용합니다.

WebGL 지원 브라우저가 필요합니다. 한글 제목 글꼴은 프로젝트에 포함되어 외부 폰트 서버에 연결하지 않습니다. 저성능 모바일에서는 기기 성능에 따라 프레임 속도가 달라질 수 있습니다.
