# 너를 위한 작은 생일 동산

Three.js 기본 도형으로 만든 파스텔 생일 정원입니다. 유료 API, 인증 키, 외부 3D 모델 없이 실행됩니다. 오르골과 효과음은 Web Audio API로 직접 합성합니다.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서:

```sh
npm ci
npm run dev
```

개발 서버의 기본 포트는 5173입니다. 배포용 파일은 `npm run build`로 `dist/`에 생성됩니다. `npm run preview`로 빌드 결과를 확인할 수 있습니다. 정적 호스팅에 `dist/`를 배포하면 링크로 선물할 수 있습니다.

## 산책하기

- WASD / 방향키: 이동, Shift: 달리기
- 마우스·터치 드래그: 카메라 회전, 마우스 휠: 줌
- E 또는 화면의 상호작용 버튼: 가까운 선물·케이크·편지와 상호작용
- 오두막 의자·별빛 정원 벤치: 가까이에서 E 또는 화면 버튼으로 앉기, 다시 E 또는 버튼으로 일어나기
- 모바일: 왼쪽 조이스틱으로 이동
- 오른쪽 위 ♫: 소리 켜기·끄기, ?: 조작 도움말

왼쪽 곰돌이 정원에서 선물 3개를 열고, 중앙 케이크에서 소원을 빌어보세요. 케이크 뒤 정자의 빛나는 봉투에는 마지막 편지가 있습니다. 케이크 이벤트는 반복할 수 있고, 열린 선물은 현재 방문 동안 열린 상태로 유지됩니다. 새로고침하면 다시 시작합니다.

## 문구 수정

`src/content.js`의 `BIRTHDAY_LETTER`와 `GIFT_MESSAGES`를 수정하세요. 소리와 멜로디는 `src/audio.js`, 월드와 이벤트는 `src/main.js`, 화면 디자인은 `src/style.css`에 있습니다.

## 검증

```sh
npm run build
npx playwright install chromium # 시스템 Chromium이 없는 경우 한 번 설치
npm test
```

브라우저 테스트는 실제 키보드 이동으로 선물 3개, 촛불 이벤트 반복, 이벤트 중 이동 정지, 편지 열기·닫기, 모바일 조이스틱, 의자·벤치 4곳에서 앉기·일어나기와 모바일 터치 버튼을 확인합니다. 시스템에 `/usr/bin/chromium`이 있으면 해당 브라우저를 사용합니다.

WebGL 지원 브라우저가 필요합니다. 한글 제목 글꼴은 프로젝트에 포함되어 외부 폰트 서버에 연결하지 않습니다. 저성능 모바일에서는 기기 성능에 따라 프레임 속도가 달라질 수 있습니다.
